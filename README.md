## 장비 선택과 진화

- 무기 6칸과 지속 보급품 6칸을 각각 사용합니다. 선택 가능한 기본 무기는 9종, 보급품은 12종입니다. 시작 무기는 자동 주사기 1성입니다.
- 경험치가 레벨 업 조건을 채우면 중복 없는 후보를 최대 3개 제시합니다. 보유 장비의 강화와 빈 슬롯에 넣을 새 장비 중 하나를 선택합니다. 무기나 보급품이 6칸을 채우면 해당 종류의 새 장비는 후보에서 빠집니다.
- 기본 장비는 5성까지 강화됩니다. 일반 무기 5성과 짝 보급품 1성 이상을 갖추면 궁극 진화(EVO)를 선택할 수 있습니다. 상자도 가능한 진화를 우선 지급합니다. 진화한 무기는 기존 슬롯을 그대로 사용합니다.
- A형·B형 의료 드론을 각각 5성으로 만들면 통합 구조 드론으로 합체합니다. 두 슬롯을 하나로 합쳐 무기 한 칸이 다시 비워집니다. 합체한 판에서는 구성 드론이 다시 후보로 나오지 않습니다.
- 진화한 무기에는 숙련 강화가 계속 등장합니다. 숙련 1단계마다 해당 무기 피해가 기본 진화 피해의 15%씩 누적 증가합니다. 보급품·영구 장갑 배율과 함께 적용하며 탄환 수나 연사 속도를 무한히 늘리지 않습니다.
- 무기 숙련 3부터 집중(해당 무기의 보스 피해 +40%) 또는 폭발(명중 지점 주변 반경 75의 다른 적에 25% 추가 피해) 중 특성 하나를 선택할 수 있습니다. 한 무기당 하나이며 그 여정 동안 유지됩니다. 상자는 숙련을 지급할 수 있지만 특성을 자동 선택하지 않습니다.
- 받을 강화가 전혀 없으면 최대 체력 30% 회복 또는 기본 금화 50개가 대체 선택지로 나옵니다. 새 여정은 해당 여정의 무기·보급품·숙련·특성·경험치·금화·필드 수집물을 초기화하고 다시 뽑기 1회를 복구합니다. 영구 장비와 재료는 유지합니다.
- 전투 HUD에서 별·숙련을 확인하고, Esc 일시정지 화면에서 전체 이름·진화 조합·선택한 특성과 영구 장비 단계를 확인할 수 있습니다. 주사기 공격력 표시는 숙련 배율을 포함하며 보스에만 적용되는 집중 배율은 제외합니다.

## 영구 장비와 체크포인트

| 영구 장비 | 강화 효과 |
| --- | --- |
| 방호복 | 단계마다 최대 체력 +15%. 추가 피해 감소는 점진적으로 증가하며 20% 미만 |
| 전술 장갑 | 단계마다 모든 무기 피해 +10%. 진화·숙련 무기에도 적용 |
| 구조화 | 단계마다 최대 체력 +5%. 추가 이동 속도는 점진적으로 증가하며 25% 미만 |

보스 보상 재료는 `8 + 구역 번호 × 3`개입니다. 같은 여정에서 같은 구역을 다시 완료해 중복 수령할 수 없습니다. 새 여정을 시작하면 다시 보스 재료를 모을 수 있으므로, 막힌 구역에서는 장비를 강화해 재도전하거나 1병동부터 재료를 모을 수 있습니다. 각 장비의 다음 강화 비용은 `5 + 현재 강화 단계 × 3`개입니다. 금화는 점수용이며 강화 재료로 사용하지 않습니다.

새 여정을 시작할 때 **1병동 시작 상태**, 보스를 쓰러뜨릴 때 **다음 구역 첫 병동 상태**를 저장합니다. 체크포인트에는 무기·보급품·숙련·특성·레벨·경험치·처치·금화·재뽑기 잔여 횟수가 포함됩니다. 영구 장비와 재료는 별도 프로필로 함께 유지하며 강화할 때 저장합니다. 종료 후 Enter로 저장된 병동부터 시작하고, 사망 후에도 마지막 체크포인트를 불러와 재도전할 수 있습니다.

**전투 도중의 위치·현재 체력·몹·바닥 아이템·병동 타이머는 저장하지 않습니다.** 예를 들어 5병동에서 종료하거나 사망하면 3병동 보스 직후 저장한 4병동 시작으로 돌아갑니다. 새 여정은 현재 체크포인트를 교체하므로, 이어서 진행하려면 Enter의 이어하기를 사용합니다.

저장 파일은 `user://hospital_campaign_v1.json`입니다. 임시 파일 검증 후 교체하고 `.bak` 백업을 유지합니다. 읽기 실패 시 오류를 표시하고 가능한 백업을 복구합니다. 보스 체크포인트 저장에 실패하면 정비실에 머물러 Enter 또는 Esc로 재시도하며, 저장이 완료되기 전에는 재료 강화와 다음 병동 이동을 진행하지 않습니다. 클라우드 계정·서버 동기화는 없습니다.

Web 배포본은 같은 사이트·브라우저의 IndexedDB에 저장합니다. 브라우저가 영구 저장소를 제공하지 않으면 오류를 표시하고 새 여정·체크포인트·강화 저장을 중단합니다. Godot의 파일 쓰기와 브라우저 저장소 동기화는 별개이며, IndexedDB 반영은 비동기입니다. 게임 안에서 파일 저장에 성공해도 즉시 탭을 닫거나 브라우저가 이후 용량 제한·사이트 데이터 삭제 등으로 저장을 거부하면 최신 진행이 남지 않을 수 있습니다. 현재 브라우저 동기화 API는 이러한 후속 오류를 게임의 저장 결과로 전달하지 않으므로, Web의 내구성은 Windows 로컬 파일 저장과 동일하게 보장하지 않습니다. 브라우저·사이트 주소를 바꾸면 저장을 공유하지 않습니다.

| 폭탄 | 화면 범위의 일반 적을 제거하고 보스에는 300 피해를 줍니다. 피해 수치는 이 게임의 설정입니다. |
| 상자 | 한 번에 1·3·5개 보상을 무작위 지급합니다. 이미 보유한 장비를 강화하며, 가능한 진화를 먼저 지급합니다. 새 무기나 새 보급품을 강제로 채우지 않습니다. |
| 금화 | 이번 도전 점수와 로컬 누적 획득 기록에 반영됩니다. 상점·유료 구매·계정 재화 기능은 없습니다. |

상자를 열 때는 장비를 순서대로 갱신하므로 앞 보상으로 진화 조건을 채우면 뒤 보상에서 진화할 수 있습니다. 레벨 업 후보와 상자 보상 모두 현재 슬롯과 최대 강화 상태를 따릅니다. 같은 병동의 미수집 드롭은 남아 있지만 다음 병동으로 이동하면 정리합니다.

참고한 원리는 자동 무기 조합, 5성 장비의 진화, 두 드론의 합체와 슬롯 반환, 화면 밖 자석·폭탄 보존입니다. [Apple App Store의 탕탕특공대 팁](https://apps.apple.com/ca/iphone/story/id1641743438)을 참고했으며, 이 프로젝트의 개별 피해량·보상량·캠페인 시간은 자체 설정입니다.

## 전투

- 주사기: 사거리 내에서 벽에 가리지 않은 가장 가까운 적을 자동 공격합니다.
- 살균 파동: 장비 선택으로 획득하는 주기적 범위 공격입니다. 강화·진화·보급품에 따라 피해와 범위·주기가 달라지며 적을 둔화합니다.
- 경험치: 가까이 가면 자동 획득하고 레벨 업마다 장비를 선택합니다. 이전 버전의 정해진 공격력·연사·체력 자동 증가는 장비 선택으로 대체했습니다.
- 접촉 피해 후 0.85초간 무적입니다. 치명적인 접촉 피해는 같은 갱신의 처치 회복보다 먼저 패배 처리합니다.
- 엘리트: 체력이 높고 주황색 원으로 범위 공격을 예고합니다. 경험치와 상자 보상을 제공합니다. 격리병동에 처음 2마리, 이후 주기적으로 추가하며 동시 6마리 이하입니다.
- 방어형 감염자: 푸른 표식, 높은 체력과 느린 이동. 원거리형은 보라색 표식으로 발사를 예고하고 탄환을 쏘며, 돌진형은 주황색 표식과 돌진 예고를 사용합니다. 구역이 진행될수록 등장 조합이 바뀝니다.
- 감독관: 돌진 방향을 고정 예고한 뒤 돌진하고 범위 공격을 이어갑니다. 벽에 막히며, 공격 후 회복 동작이 있습니다. 체력 절반 이하에서 이동과 공격 주기가 빨라집니다. 2구역 이후에는 방사형 탄환 패턴도 추가됩니다. 도망쳐 화면 밖으로 멀어져도 보스 체력은 유지되고 다시 추적합니다.
- 최고 누적 생존 시간·처치 수·완료 병동 수·누적 금화를 `user://hospital_records.cfg`에 저장합니다.

## 맵과 그래픽

응급병동은 청록색 병실·복도, 격리병동은 따뜻한 경고색과 커튼, 수술동은 푸른 조명과 넓은 회피 공간으로 구분합니다. 병원 모듈이 사방으로 연결되며 주변 9개만 유지합니다. 구조와 충돌이 일치하도록 병실 가구와 수술동 외곽 가구를 배치했습니다.

병원과 적은 초기 승인 이미지 2장을 재사용합니다. 이후 별도 승인한 호출로 의료진 앞·뒤·옆 idle/walk 24프레임을 만들었습니다. 각 방향의 idle은 4프레임·4fps, walk는 4프레임·8fps 루프이며 왼쪽은 옆모습의 수평 반전입니다. 대각선은 가까운 4방향 중 하나로 표시합니다. 엘리트·보스의 크기·색·표식·공격 예고는 Godot에서 처리합니다.

동시 적은 48마리, 보스 병동에서는 일반 생성 목표를 22마리로 제한합니다. 경험치 표시 개체·추가 무기 투사체·파티클·충격파에 상한이 있습니다. 경험치 표시 개체를 합쳐도 보상 값은 사라지지 않습니다. 적 경로·시야 계산을 분산하고 화면 밖 모듈은 그리지 않습니다.

숙련은 피해량을 늘리고, 영구 장비는 피해·체력을 늘리는 방식으로 성장합니다. 보급품은 5성 제한을 유지합니다. 적 이동 속도의 구역 배율은 최대 1.35배, 영구 방호복의 추가 피해 감소는 20% 미만, 구조화의 추가 속도는 25% 미만으로 제한합니다. 기본 주사기 탄환 80개·추가 무기 투사체 128개·적 탄환 80개·추가 효과 80개의 개수 제한도 유지합니다. 수학적 무한 저장을 의미하지는 않으며 저장 검증의 안전 범위는 병동·레벨 10억, 영구 장비 단계 100만, 재료 1조입니다. 일반 플레이에서 종료 지점을 두는 대신 반복 진행과 정비를 제공합니다.
