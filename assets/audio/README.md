# 끝없는 병원 오디오

## 배경음

사용자 제공 `C:/Users/na/Downloads/The_Final_Perimeter.mp3`를 변경 없이 `bgm/default.mp3`로 복사했다. SHA-256이 원본과 일치한다. 약 178.129초, 44.1kHz 스테레오 MP3. Godot AudioStreamMP3로 직접 재생하며 WAV 변환·외부 서비스·과금 호출은 수행하지 않았다.

1~3병동 공통 전투곡으로 반복하며 병동 전환 때 같은 트랙은 다시 시작하지 않는다. 파일을 추가해 병동별 곡을 지정하려면 [BGM 안내](bgm/README.md)를 따른다. 타이틀에는 아직 별도 BGM이 없다. 음원 출처는 사용자 제공으로 기록하며 별도 라이선스를 임의로 부여하지 않는다.

## 효과음

`tools/make-hospital-sfx.py`에서 NumPy·수학식·시드 고정 노이즈로 직접 합성했다. AI 제공자·샘플 라이브러리·네트워크·유료 API 없이 로컬 제작했다. 22종·33개, 48kHz/모노/PCM16 WAV. [PROVENANCE.json](sfx/PROVENANCE.json)에 길이·피크·해시를 기록했다.

발사·명중·적 처치·피격·경험치·레벨업·살균 펄스·엘리트 예고·보스 돌진 예고·범위 예고·돌진·착지·폭주·보스 등장·병동 클리어·승리·패배·메뉴·시작·정지·재개·발소리다. 반복 이벤트는 변형을 무작위 선택하고 최소 간격을 둔다. 공격 예고의 재생 속도는 변경하지 않는다.

동시 전투 효과음 최대 16개 중 4개는 중요한 소리용으로 예약한다. UI 정지·재개는 별도 1개, BGM 1개다. 멀리 있는 이벤트는 작게 들리며 1000px 밖은 생략한다. 경고·피격·완료음 동안 BGM을 일시적으로 낮춘다. M 음소거와 일시정지·포커스 상실에 연동한다.

검증: WAV 무음 끝점·피크 여유·길이 검사, Godot 33개 파일 로드·경고 길이·반복 제한·예약 슬롯·MP3 디코드/반복·병동 간 연속성·일시정지/재개·음소거·테스트 음소거 통과. MCP로 실행한 실제 Windows 재생에서도 0.5초 뒤 재생 위치 약 0.342초와 정지/재개/음소거를 확인했다. 사용자 스피커의 체감 음량은 기기 설정에 따라 달라진다.
