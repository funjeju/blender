# 직접 준비할 배경음

이 폴더에 아래 이름으로 파일을 넣고 Godot에서 다시 실행하면 해당 화면·병동에서 재생합니다. OGG를 권장하며 WAV·MP3도 지원합니다. 같은 이름은 한 형식만 두세요.

- `title.ogg`: 시작 화면
- `stage_1.ogg`: 응급병동
- `stage_2.ogg`: 격리병동
- `stage_3.ogg`: 수술동 보스
- `default.mp3`: 병동별 파일이 없을 때 사용하는 공통 전투 배경음. 현재 사용자가 제공한 The_Final_Perimeter.mp3를 원본 그대로 복사했다. 병동이 바뀌어도 같은 트랙은 처음부터 다시 재생하지 않는다.

파일이 없는 병동은 효과음만 재생하며 오류로 처리하지 않습니다. 기본 음악 음량은 효과음보다 낮고 공격 예고 중 더 낮아집니다. M으로 전체 음소거, 일시정지·포커스 상실 때 음악도 멈춥니다. 현재 전환은 병동 진입 시 트랙 교체이며 크로스페이드는 후속 작업입니다.

게임에 포함해 배포할 수 있는 라이선스의 음원을 준비하고 출처·라이선스 파일도 함께 보관하세요. 음원 생성·다운로드·유료 서비스 연결은 이 작업에서 실행하지 않았습니다.
