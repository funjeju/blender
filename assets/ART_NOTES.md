# Art production notes

Date: 2026-10-23
Method: OpenAI built-in `image_gen` tool, transparent background enabled for both calls. No API-key workflow or paid fallback was used.
Approved scope: two calls total, one hospital/background atlas and one character sheet. The user explicitly approved the cost uncertainty. Two calls were used; no retries or additional calls were made. The actual billed amount is not exposed by this tool.

The originals are copied into this project as `hospital_atlas.png` and `characters_atlas.png`. Original output dimensions are 1254×1254. The game uses four quadrant AtlasTextures per sheet and computes bounds above an alpha threshold to ignore faint padding specks. The source images are preserved. Runtime drawing combines these textures with code-native walls, lights, shadows and UI.

## Prompt 1 — hospital_atlas.png

Use case: stylized-concept. Asset type: actual production texture atlas for a top-down 2D hospital survival game. Create ONE square PNG texture atlas in a precise 2 by 2 layout of four equally sized square cells, no dividers, no text, no labels, no UI. Strict orthographic overhead camera, no isometric perspective. Consistent sophisticated hand-painted game art, desaturated blue-gray ceramic, dark petrol teal accents, softly worn, clinical eerie midnight hospital, clear silhouettes. Upper left cell: a perfectly square seamless hospital ceramic floor tile texture filling the ENTIRE upper-left quadrant edge to edge, 8x8 small square tiles, subtle scuffs, pale gray-green, no props or walls, even illumination and no large black stains. Upper right cell: one hospital bed viewed exactly from above, pillow at top, faded cream linen with subtle folds, teal mattress frame, side rails and small caster wheels; bed centered with generous transparent margins. Lower left cell: one detailed medical supply trolley from directly above, stainless frame, trays, bandages, bottles, small red first aid box, centered with transparent margins. Lower right cell: one examination desk/medical monitoring station from directly above, keyboard, softly glowing cyan monitor, papers, drawers, centered with transparent margins. Every prop entirely within its own quadrant. Preserve truly transparent background behind all three props, but floor quadrant fully opaque. No characters, no lettering, no watermarks. Crisp detailed readable 2D game assets; all lighting from upper left.

## Prompt 2 — characters_atlas.png

Use case: stylized-concept. Asset type: production character sprite atlas for an orthographic top-down hospital survival game. One square image precisely divided into a 2 by 2 equal-cell layout, no lines or text. Four isolated full-body characters, each centered within its quadrant, consistent scale, ample transparent padding. Sophisticated detailed hand-painted 2D game style with realistic fabric shading and strong readable silhouettes. Camera high overhead at about 65 degrees, heads and shoulders visible but also legs, all four facing DOWN toward viewer, feet pointing down, NOT isometric side view. Upper-left: brave young medical survivor in pale teal scrubs, short dark hair, pale jacket, compact silver medical injector gun held forward, dark trousers, teal accent. Upper-right: back-facing version of the exact same teal doctor facing UP, head and back visible, same outfit and same scale. Lower-left: shambling infected hospital patient in faded cream hospital gown, muted gray-green skin, rust-red stained fabric, arms hanging forwards, no graphic injury. Lower-right: fast infected patient in dark burgundy scrubs, lean hunched silhouette, grayish skin, long arms, no graphic injury. Every entire character contained inside their own quadrant, perfectly transparent background, no ground, no floor, no text, no labels, no panels, no glow halos. Lighting from upper-left. Crisp separable silhouettes. This must be real sprite artwork, not a mockup or screenshot.
